# OpenStick.tv

Planning home for OpenStick.tv: the product requirements, decision records and roadmap. Code lives in the other repos in [opensticktv](https://github.com/opensticktv).

- [PRD](docs/PRD.md) (revision 2). Revision 1 is kept as [PRD.original.md](docs/PRD.original.md).
- [Decision records](decisions/): one file per significant decision, with status `proposed`, `accepted` or `superseded`.
- Roadmap: phase gates are tracked as milestones and issues in this repo.

## Phases

`v0 prototype → board spike → v1 alpha → site and beta → v1 GA`. Each phase ends with a test on hardware, not a date. See the PRD's Milestones section.
