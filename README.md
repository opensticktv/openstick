# OpenStick.tv

Planning home for OpenStick.tv: the product requirements, decision records and roadmap. Code lives in the other repos in [opensticktv](https://github.com/opensticktv).

OpenStick is a 4K streaming stick on a certified Android TV platform, with an open layer on top: an ad-free launcher, open casting receivers, Home Assistant, Matter and HomeKit control, a local API, and published enclosure designs.

- [PRD](docs/PRD.md) (revision 3). Earlier directions are kept: [fully open Linux edition](docs/PRD.open-linux-edition.md) (revision 2) and [revision 1](docs/PRD.original.md).
- [Decision records](decisions/): one file per significant decision, with status `proposed`, `accepted` or `superseded`. The key one is [0008](decisions/0008-certified-base-open-layer.md).
- Roadmap: phase gates are tracked as milestones and issues in this repo.
