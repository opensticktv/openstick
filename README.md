# OpenStick.tv

Planning home for OpenStick.tv: the product requirements, decision records and roadmap. Code lives in the other repos in [opensticktv](https://github.com/opensticktv).

OpenStick is a 4K streaming stick you can buy, built on open hardware: the board and case designs are published, units ship locked so 4K streaming works, and owners can unlock their own. On top: an ad-free launcher, open casting receivers, Home Assistant, Matter and HomeKit control, and a local API.

- [PRD](docs/PRD.md) (revision 4). Earlier directions are kept: [fully open Linux edition](docs/PRD.open-linux-edition.md) (revision 2) and [revision 1](docs/PRD.original.md).
- [Decision records](decisions/): one file per significant decision, with status `proposed`, `accepted` or `superseded`. The key ones are [0008](decisions/0008-certified-base-open-layer.md) and [0009](decisions/0009-open-hardware-locked-by-default.md).
- Roadmap: phase gates are tracked as milestones and issues in this repo.
